# Gemini 3.8 Flash TTS

_Гайд по сценариям озвучки: теги, стили, голоса и формат текстового файла для скрипта `voice.py`_

## 1. Как устроено управление речью

Модель читает текст **строго дословно**. Всё, что написано в поле текста, будет произнесено, поэтому ремарки вроде `Say cheerfully:` или `Speaker 1:` писать в текст нельзя. Управление разделено на три уровня:

| Уровень | Где задаётся | Что туда писать |
|---|---|---|
| Голос | Speaker settings / Voice Design / VOICES в скрипте | Постоянные черты: пол, возраст, тембр, текстура, акцент, базовый темп и характер. Задаётся один раз. |
| Style | Меню **Style** у блока (пресет или своё поле) / текст после двоеточия в `@Имя: style` | Подача на весь блок: эмоция, темп, интонация, громкость. Коротко, 3–8 слов. Необязательно. |
| Теги `<...>` | Прямо в тексте (кнопка **+ Expression** или ввод `<`) | Разовые события в конкретной точке: смех, вздох, вдох, пауза. Срабатывают один раз. |

## 2. Интерфейс AI Studio (Speech Playground)

| Элемент | Что делает |
|---|---|
| Speaker 1 / Speaker 2 | Выбор голоса для блока. До 2 спикеров в одном диалоге. |
| Style | Пресеты (Whisper, Friendly, Narration, Promote, Podcast) и текстовое поле сверху для своего стиля. |
| + Expression | Вставка инлайн-тегов. То же самое — набрать `<` прямо в тексте. |
| Add speech block | Новый блок = новая реплика или смена эмоции/стиля внутри реплики. |
| Temperature | Разброс между прогонами. 1 = больше живости и вариативности, 0.5–0.7 = стабильнее. |
| Get code | Код запроса для API. Для пакетной работы используй `voice.py` (он в актуальном формате 3.8). |
| History | TTS-сессии туда **не сохраняются**. Понравившийся результат сразу скачивай. |

## 3. Инлайн-теги

Пиши в угловых скобках `<...>` и ставь ровно в том месте, где должен прозвучать звук. Теги всегда **на английском**, даже если текст на русском.

### Смех

| Тег | Что это | Когда использовать |
|---|---|---|
| `<laugh>` / `<laughter>` | Обычный смех, «ха-ха» | Реакция на шутку, нормальный живой смех |
| `<chuckle>` / `<chuckles>` | Тихий смешок, «хм-хм», смех себе под нос | Лёгкая ирония, «ну да, забавно». Самый частый в подкастах |
| `<giggle>` | Хихиканье, высокое и короткое | Игриво, по-детски, смущённо |
| `<snicker>` | Ехидный сдержанный смешок в нос | Насмешка, «я-то знаю, в чём подвох» |
| `<cackle>` | Громкий каркающий хохот, «злодейский» | Комедия, злодей, гипербола |

### Дыхание

| Тег | Что это | Когда использовать |
|---|---|---|
| `<breath>` | Обычный вдох | Перед длинной фразой, для естественности |
| `<heavy breath>` | Тяжёлое шумное дыхание | Усталость, напряжение, после нагрузки |
| `<exhales>` | Выдох | Расслабление, «ну всё», собраться с мыслями |
| `<pant>` | Частое прерывистое дыхание, запыхался | После бега, паника, спешка |
| `<sigh>` / `<sighs>` | Вздох | Усталость, разочарование, «эх» |
| `<phew>` | «Фух!» | Облегчение: «фух, пронесло» |
| `<pff>` | «Пфф» | Пренебрежение, скепсис: «пфф, да ну» |
| `<yawn>` | Зевок | Скука, сонливость |

### Реакции

| Тег | Что это | Когда использовать |
|---|---|---|
| `<gasp>` | Резкий вдох от удивления, «ах!» | Шок, удивление, неожиданный поворот |
| `<cough>` | Кашель | Неловкость, «кхм», комичный момент |
| `<sneeze>` | Чих | Редко, для комедии |
| `<throat-clearing>` | Прочистить горло, «кхе-кхе» | Перед важным заявлением, неловкая пауза, «итак...» |
| `<snort>` | Фырканье, хрюкающий смешок через нос | Смех, вырвавшийся против воли, или презрительное «хмпф» |
| `<tsk>` | Цоканье языком, «ц-ц-ц» | Неодобрение, досада: «ц, ну как так» |

### Эмоциональные звуки

| Тег | Что это | Когда использовать |
|---|---|---|
| `<sob>` | Всхлип | Плач, сильное горе |
| `<cry>` | Плач | Драма, грусть |
| `<whimper>` | Хныканье, жалобное поскуливание | Страх, жалость к себе, «ну пожалуйста» |
| `<groan>` | Стон досады, «ыыых» | «Опять этот баг...», усталость, раздражение |
| `<moan>` | Стон (от боли или усталости) | Боль, изнеможение |
| `<argh>` | «Аргх!» | Злость, фрустрация: «аргх, не работает!» |

### Громкие

| Тег | Что это | Когда использовать |
|---|---|---|
| `<scream>` | Крик от страха или ужаса | Хоррор, испуг |
| `<shout>` | Выкрик, окрик | Позвать, выделить, эмоциональный всплеск |
| `<shriek>` | Визг, пронзительный высокий крик | Сильный испуг или восторг |
| `<cheer>` | Радостный возглас, «ура!», «йе-е!» | Победа, хайп, празднование |

### Агрессивные

| Тег | Что это | Когда использовать |
|---|---|---|
| `<growl>` | Низкое рычание | Угроза, злость |
| `<grunt>` | Кряхтение, короткое «хм» от усилия | Поднять что-то тяжёлое, недовольное «угу» |
| `<grr>` | «Ррр!» раздражения | Злость, но скорее комично |
| `<hiss>` | Шипение, «тсс» | Злобно или «тише!» |

### Шёпот и паузы

| Тег | Что это | Когда использовать |
|---|---|---|
| `<whispers>` / `<whispering>` | Переход на шёпот | Секрет, интрига. Для шёпота на весь блок лучше Style: Whisper |
| `<short pause>` | Короткая пауза (около полсекунды) | Перед важным словом, для ритма |
| `<long pause>` | Длинная пауза (секунда и больше) | Драматический момент, «дать осмыслить» |

### Правила для тегов

- Минимальный набор для подкаста или обзора: `<chuckle>`, `<laugh>`, `<breath>`, `<sigh>`, `<short pause>`, `<gasp>`. Остальное — для скетчей и сторителлинга.
- Только человеческие звуки. Звуковые эффекты (аплодисменты, удары, музыка) не использовать.
- Не ставь два тега вплотную: разделяй их словом или знаком препинания. Так стабильнее.
- Теги из старых гайдов в `[квадратных скобках]` — формат модели 3.1. Для 3.8 используй угловые скобки.

## 4. Style — подача на весь блок

### Пресеты AI Studio

| Пресет | Что внутри | Когда использовать |
|---|---|---|
| `Whisper` | whisper quietly | Секрет, интрига, ASMR-подача |
| `Friendly` | Warm and neutral delivery with micro-pauses | Дружелюбное объяснение, туториал |
| `Narration` | commanding, rich vocal modulation, dramatic pauses | Документалка, сторителлинг, трейлер |
| `Promote` | High energy, elongated vowels | Реклама, анонс, хайп-интро |
| `Podcast` | Calm, measured delivery | Спокойный разговорный формат |

### Свой style: примеры

| Задача | Пример style |
|---|---|
| Эмоция | `cheerful and friendly`, `angry tone`, `sarcastic`, `deadpan, unimpressed`, `panicked` |
| Темп | `speaking rapidly`, `speaking slowly` |
| Интонация и высота | `high pitch, cheerful and excited inflection`, `monotone and flat` |
| Манера | `whispering, conspiratorial`, `out of breath`, `muttering`, `muttering, then reassuring` |
| Базовая подача | `casual, friendly`, `calm, slightly amused`, `warm and enthusiastic` |

### Правила для style

- Сначала попробуй **без style**. Хорошо сделанный голос и так звучит в своём характере. Style добавляй только туда, где нужна корректировка.
- Коротко: 3–8 слов. Для единой подачи повторяй одну и ту же строку в разных блоках.
- Эмоция меняется посреди реплики — раздели её на два блока с разными style.
- Не пиши в style возраст, пол, имя или акцент — это свойства голоса (Voice Design).
- Не пиши длинные «Director's Notes» и просьбы вроде `maintain identical timbre` — они усиливают дрейф голоса.

## 5. Паузы, темп и ударение

| Инструмент | Как работает | Пример |
|---|---|---|
| Пунктуация | Запятые, тире и многоточия дают естественные заминки | `Hold on -- let me think...` |
| Теги пауз | Пауза в точном месте | `Wait... <short pause> did you hear that?` |
| Style | Темп на весь блок | `speaking slowly` / `speaking rapidly` |
| КАПС | Логическое ударение на слове | `This is a VERY important point!` |

## 6. Бэкченнелы и перебивания

В диалоге двух спикеров реакция слушателя пишется в вертикальных чертах `|...|` **внутри реплики говорящего**. Её произносит второй спикер поверх речи первого, без отдельного блока.

| Приём | Пример |
|---|---|
| Поддакивание | `So the launch is Thursday \|oh hmm\| Are we actually ready?` |
| Уточнение | `Relax. Autosave is on \|it is?\| every five minutes.` |
| Хор / отсчёт | `one. two. three. \|happy\| happy \|birthday\| birthday!` |
| Полное наложение | `Hello \|oh\| there \|my\| it \|goodness\| must \|gracious\| be...` |

> Бэкченнелы работают только когда оба спикера в одном запросе: в Playground и в режиме диалога скрипта. В режимах `--lines` и с таймкодами скрипт вырезает их автоматически.

## 7. Как писать текст, чтобы звучало живо

- Пиши как реальную речь, с запинками: `Oh uh yeah I think... hm, so that's interesting`.
- Короткие фразы звучат естественнее длинных. Длинный монолог лучше разбить на несколько блоков.
- Произношение сложных слов можно попробовать задать в МФА между слешами: `/ˈɡɪf/`. Функция экспериментальная.
- Для русского текста теги и style всё равно пиши по-английски.

| Способ | Что это | Когда брать |

### Как описывать голос в Voice Design

- 1–2 предложения, только постоянные черты. Длинные и противоречивые описания дают нестабильный результат.
- Пример: `A relaxed, low-pitched male tech storyteller in his mid-30s with a slightly gravelly, warm timbre, neutral American accent, and a dry, amused edge.`
- Для русской озвучки создавай голос с русским языком или бери голос из библиотеки с фильтром по русскому.

| Параметр | Примеры описаний |
|---|---|
| Пол и возраст | male, late 30s |
| Высота | low / medium / high pitch |
| Тембр и текстура | warm, gravelly, breathy, nasal, raspy, smooth, resonant |
| Акцент | slight Irish accent, neutral American, Eastern European |
| Темп | fast-talking, relaxed, deliberate |
| Энергия | high-energy, laid-back, deadpan |
| Типаж | tech reviewer, storyteller, sports announcer, late-night radio host |
| Особенности | crisp diction, drawn-out vowels, smirk in the voice |

## 9. Голос «в духе» референса

Скопировать чужой голос без согласия нельзя, но можно сделать голос с похожим характером. Voice Design принимает только текст, поэтому описание получаем через мультимодальный Gemini.

1. Открой обычный чат AI Studio с моделью **Gemini 3.8 Flash** (не TTS).
2. Прикрепи 10–60 секунд чистой речи без музыки и вставь промпт ниже.
3. Раздел 1 ответа вставь в Voice Design, раздел 2 — в Style, раздел 3 подскажет теги, раздел 6 — тестовая фраза. Не попал — попробуй альтернативы из раздела 5.

```
You are a voice casting director and audio engineer. Listen carefully to the
attached audio and analyze the SPEAKER'S VOICE only (ignore content, music, and
sound effects).

Output exactly these sections:

1. VOICE DESIGN PROMPT
One or two concise sentences in English describing only permanent vocal traits:
gender, approximate age, pitch, timbre and texture (e.g. warm, gravelly, breathy,
nasal, resonant), accent, baseline pace, energy, and persona archetype. Do not
mention the speaker's name or any identifying details. No contradictions, no lists.

2. STYLE STRING
A short style phrase (3-8 words) describing the typical delivery in this clip,
e.g. "casual, amused, speaking rapidly".

3. VOCAL HABITS -> TAGS
List recurring non-verbal habits you hear (laughs, breaths, sighs, pauses,
throat-clearing) and map each to one of these tags: <laugh> <chuckle> <giggle>
<breath> <heavy breath> <sigh> <exhales> <gasp> <throat-clearing> <tsk>
<short pause> <long pause>. Also note emphasis patterns and filler words.

4. PARAMETER TABLE
Gender | Age | Pitch (low/medium/high) | Timbre | Texture | Accent | Pace | Energy | Persona

5. TWO ALTERNATIVE VOICE DESIGN PROMPTS
One slightly warmer/softer, one slightly more energetic/sharper, 1-2 sentences each.

6. SAMPLE SCRIPT
A 3-4 line test script in the speaker's typical manner, using the tags where
they naturally occur.
```

Если референс на YouTube, файл можно не скачивать: ссылку можно разобрать через NexLev в Claude по тому же шаблону.

## 10. Ограничения и подводные камни

| Ситуация | Что происходит | Что делать |
|---|---|---|
| Кастомный голос в диалоге | В одном запросе диалога работают только встроенные голоса | Встроенные голоса или режим `--lines` |
| Больше 2 спикеров | Диалог в одном запросе ограничен двумя | Режим `--lines` |
| Русский текст | Язык поддерживается, определяется автоматически | Проверь, что голос создан под русский |
| Одинаковый дубль | При Temperature 1 каждый прогон звучит по-разному | Скачивай сразу; для стабильности 0.5–0.7 |
| Ремарки в тексте | Модель может их прочитать вслух | Только style и теги |
| Реплика не влезает во время | Модель не знает целевой длительности | Таймкоды + `--fit` в скрипте |

## 11. Формат сценария в текстовом файле

Сценарий для `voice.py` — обычный текстовый файл в кодировке UTF-8 (например `dialogue.txt`). Он состоит из блоков: строка-заголовок и под ней текст реплики.

### Синтаксис

| Строка | Значение |
|---|---|
| `@Имя` | Новый блок, спикер без style |
| `@Имя: style` | Новый блок со style (всё после двоеточия) |
| `@00:12.5 Имя: style` | Новый блок с таймкодом начала реплики |
| текст | Реплика с тегами `<...>`, капсом и бэкченнелами `\|...\|`. Несколько строк склеиваются в одну |
| `# ...` | Комментарий, игнорируется |
| пустая строка | Игнорируется, можно использовать для читаемости |

### Правила

- Файл должен начинаться со строки `@Имя`.
- Имя спикера должно совпадать с ключом в блоке `VOICES` в `voice.py` (регистр важен).
- Таймкоды ставятся либо у **всех** реплик, либо ни у одной.
- Форматы таймкодов: `мм:сс`, `мм:сс.доли`, `чч:мм:сс`, `чч:мм:сс:кадры` (для кадров указывай `--fps`).
- Окно реплики = время до таймкода следующей. Если реплика длиннее, она налезет; это видно в `report.txt`.

### Пример: диалог без таймкодов (dialogue.txt)

```
# Тестовый диалог. Формат: @Имя: style (style можно не писать)

@Alex
<breath> Okay Max, the render's almost done. Ninety-eight percent |uh-huh|
ninety-nine... <gasp> WAIT. Why did it freeze?!

@Max: deadpan, unimpressed
<sigh> Because you didn't save the project. Again. <short pause> Am I right?

@Alex: panicked, speaking rapidly
I... <tsk> no, I saved it! I think. <groan> That's FOUR hours of editing, Max.

@Max: calm, slightly amused
<chuckle> Relax. Autosave is on |it is?| every five minutes.

@Alex
<long pause> ...it is? <phew> Oh thank god. I thought my career was over.

@Max: dry, sarcastic
<laugh> Your career ended when you put music over your voice for the whole video.
```

### Пример: сценарий с таймкодами (timed.txt)

```
@00:00.5 Alex
<breath> Okay Max, the render's almost done. Ninety-nine percent...
<gasp> WAIT. Why did it freeze?!

@00:06 Max: deadpan, unimpressed
<sigh> Because you didn't save the project. Again.

@00:09.5 Alex: panicked, speaking rapidly
I... <tsk> no, I saved it! I think. <groan> That's FOUR hours of editing, Max.

@00:15 Max: calm, slightly amused
<chuckle> Relax. Autosave is on. Every five minutes.
```

### Чек-лист перед запуском

- Каждое имя после `@` есть в `VOICES`.
- В тексте нет ремарок вроде `Say cheerfully:` — только теги и style.
- Теги на английском, в угловых скобках, не стоят вплотную друг к другу.
- Style короткий или пустой; эмоция внутри реплики меняется — разбито на блоки.
- Для таймкодов: оставлено запаса по времени, длинные реплики сокращены заранее.
