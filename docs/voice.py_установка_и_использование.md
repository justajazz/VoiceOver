# voice.py — установка и использование

_Скрипт для озвучки сценариев через Gemini 3.8 Flash TTS на Windows (PowerShell)_

## 1. Что нужно

| Компонент | Зачем | Статус / проверка |
|---|---|---|
| Python 3.13 | Запуск скрипта | Уже установлен. Проверка: `python --version` |
| FFmpeg | Ускорение реплик при `--fit` | Уже установлен. Проверка: `ffmpeg -version` |
| google-genai | Библиотека для Gemini API | **Установить** (шаг 2) |
| API-ключ Gemini | Доступ к модели | Иконка ключа в левом нижнем углу AI Studio |

## 2. Установка

### Библиотека

```
pip install -U google-genai
```

### API-ключ

Только для текущего окна PowerShell:

```
$env:GEMINI_API_KEY="твой_ключ"
```

Навсегда (выполнить один раз, затем переоткрыть PowerShell):

```
setx GEMINI_API_KEY "твой_ключ"
```

### Файлы

Положи в одну папку `voice.py` и сценарии (`dialogue.txt`, `timed.txt`), затем перейди в неё:

```
cd "D:\Voice\test"
```

Путь проще всего скопировать из адресной строки Проводника.

## 3. Настройка голосов

Открой `voice.py` в любом редакторе. В начале файла блок настроек:

```
MODEL = "gemini-3.8-flash-tts"   # или "gemini-3.8-flash-lite-tts" (дешевле и быстрее)

VOICES = {
    "Alex": "Puck",
    "Max": "Charon",
}

OUTPUT_DIR = "output"
```

- Ключ (`"Alex"`) — имя спикера в сценарии после `@`.
- Значение — встроенный голос (`Puck`, `Charon`, `Fola`...) или ID своего голоса из Voice Design (`voice_...`).
- Добавил спикера в сценарий — добавь его сюда, иначе скрипт остановится с ошибкой.

## 4. Режимы работы

| Команда | Что делает | Результат |
|---|---|---|
| `python voice.py dialogue.txt` | Весь диалог одним запросом. Естественные переходы и бэкченнелы `\|...\|`. До 2 спикеров, только встроенные голоса | `dialogue.wav` |
| `python voice.py dialogue.txt --lines` | Каждая реплика отдельным запросом. Работают свои голоса `voice_...` и любое число спикеров | `01_Alex.wav`, `02_Max.wav`... + `full.wav` |
| `python voice.py timed.txt` | Сценарий с таймкодами: реплики раскладываются по времени | реплики + `timeline.wav` + `report.txt` |
| `python voice.py timed.txt --fit` | То же + подгонка реплик, которые не влезают в своё окно | то же, длинные реплики подогнаны |

> Режим с таймкодами включается автоматически, если таймкоды стоят у всех реплик. Флаг `--lines` в этом случае не нужен.

## 5. Параметры

| Параметр | По умолчанию | Что делает |
|---|---|---|
| `--lines` | выкл. | Каждая реплика отдельным файлом + склейка `full.wav` |
| `--gap 0.5` | 0.3 | Пауза между репликами в `full.wav`, секунды |
| `--fit` | выкл. | Подгонка длинных реплик: сначала перегенерация со style `speaking rapidly`, потом ускорение через FFmpeg |
| `--max-speed 1.15` | 1.2 | Максимальное ускорение FFmpeg. Больше 1.2 заметно на слух |
| `--retries 2` | 1 | Сколько раз перегенерировать реплику быстрее (каждый раз — платный запрос) |
| `--fps 30` | 25 | Частота кадров для таймкодов вида `чч:мм:сс:кадры` |
| `--start 01:00:00:00` | — | Таймкод начала монтажки (в DaVinci по умолчанию 01:00:00:00) |

## 6. Что получается на выходе

Каждый запуск создаёт новую папку, поэтому ничего не перезаписывается:

```
output\
  2026-09-26_18-30-12\
    script.txt                  копия сценария этого запуска
    dialogue.wav                режим диалога
    01_Alex.wav, 02_Max.wav     режим --lines
    full.wav                    режим --lines, склейка
    01_00m00.50s_Alex.wav       режим таймкодов, реплика с временем в имени
    timeline.wav                режим таймкодов, дорожка от 00:00
    report.txt                  режим таймкодов, отчёт
```

### Как читать report.txt

```
[01] 00:00.50 Alex   длина  5.50 с | окно 5.50 с | OK ускорено x1.10
[02] 00:06.00 Max    длина  4.17 с | окно 3.50 с | НАЛЕЗАЕТ на следующую на 0.67 с
[06] 00:23.00 Max    длина  5.79 с | окно   —   с | OK
```

- **длина** — сколько звучит реплика; **окно** — время до следующей реплики (у последней окна нет).
- **OK** — влезает. Пометка справа: что сделал `--fit` (перегенерировал или ускорил).
- **НАЛЕЗАЕТ** — реплика перекрывает следующую. В `timeline.wav` они будут звучать одновременно. Сократи текст или сдвинь таймкод.

## 7. Работа с видеорядом

1. В Premiere или DaVinci пройди по видео и выпиши таймкоды, где должна начинаться каждая реплика.
2. Запиши их в сценарий: `@00:12.5 Max: calm` (или в формате монтажки `@01:00:12:10 Max` с `--fps`).
3. Запусти `python voice.py timed.txt --fit` (для DaVinci добавь `--start 01:00:00:00`).
4. Проверь `report.txt`, исправь налезающие реплики и перезапусти.
5. Положи `timeline.wav` в начало таймлайна — реплики совпадут с видео. Для ручной подстройки используй отдельные файлы реплик.

## 8. Ошибки и решения

| Сообщение | Причина | Что делать |
|---|---|---|
| Не найден GEMINI_API_KEY | Ключ не задан в этом окне | `$env:GEMINI_API_KEY="..."` или `setx` и переоткрыть PowerShell |
| ModuleNotFoundError: google | Библиотека не установлена | `pip install -U google-genai` |
| Нет голоса для спикеров [...] | Имя из сценария отсутствует в `VOICES` | Добавить имя в `VOICES` (регистр важен) |
| В режиме диалога максимум 2 спикера | В сценарии больше двух имён | Запустить с `--lines` |
| Свои голоса (voice_...) в одном диалоге не поддерживаются | Ограничение API | Запустить с `--lines` |
| Таймкоды должны быть у всех реплик | У части блоков нет таймкода | Добавить таймкоды или убрать все |
| Таймкод ... раньше начала монтажки | Неверный `--start` | Проверить `--start` и таймкоды |
| ffmpeg не найден | FFmpeg не в PATH | Проверить `ffmpeg -version` в том же окне |
| 429 RESOURCE_EXHAUSTED | Лимит запросов или потолок трат | Подождать; проверить Dashboard → Usage и Spend |

## 9. Расходы

- Платный уровень **Tier 1**: системный потолок около €215 ($250) в месяц на весь платёжный аккаунт. Это максимум, а не сумма к оплате.
- Свой лимит на проект: AI Studio → вкладка **Spend** → **Monthly spend cap** (например, €20).
- `--fit` и `--retries` делают дополнительные запросы. Для экономии сначала запускай без `--fit` и смотри `report.txt`.
- `gemini-3.8-flash-lite-tts` в `MODEL` — дешевле и быстрее, качество немного ниже.
