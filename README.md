# VoiceOver

Скрипт и гайды для озвучки сценариев через **Gemini 3.8 Flash TTS** (Google AI Studio / Gemini API).

Пишешь сценарий в обычном текстовом файле — получаешь WAV: весь диалог целиком, каждую реплику отдельным файлом или готовую дорожку, разложенную по таймкодам под видеоряд.

## Возможности

- Диалог двух спикеров одним запросом, с естественными переходами и бэкченнелами `|угу|`
- Каждая реплика отдельным файлом + склейка — удобно для монтажа, работают свои голоса из Voice Design
- Сценарий с таймкодами → `timeline.wav` от 00:00 и отчёт, какие реплики не влезают в своё окно
- `--fit`: автоподгонка длинных реплик (перегенерация быстрее + ускорение через FFmpeg без изменения высоты голоса)
- Таймкоды из Premiere / DaVinci, включая формат с кадрами и старт монтажки `01:00:00:00`

## Быстрый старт

```powershell
pip install -U google-genai
$env:GEMINI_API_KEY="твой_ключ"

python voice.py dialogue.txt            # весь диалог одним файлом
python voice.py dialogue.txt --lines    # каждая реплика отдельно + full.wav
python voice.py timed.txt --fit         # по таймкодам под видео
```

Результаты сохраняются в `output/<дата_время>/`.

## Формат сценария

```
@Max: deadpan, unimpressed
<sigh> Because you didn't save the project. Again.

@00:15 Alex: calm, slightly amused
<chuckle> Relax. Autosave is on.
```

`@Имя: style` — заголовок блока (style необязателен), таймкод перед именем — необязателен. Голоса для имён задаются в блоке `VOICES` в начале `voice.py`.

## Файлы

| Файл | Что это |
|---|---|
| `voice.py` | Скрипт озвучки |
| `dialogue.txt` | Пример диалога без таймкодов |
| `timed.txt` | Пример сценария с таймкодами |
| `docs/Gemini_TTS_гайд_по_сценариям.pdf` | Все теги, style, голоса, Voice Design, формат сценария |
| `docs/voice.py_установка_и_использование.pdf` | Установка, режимы, параметры, ошибки и решения |

## Требования

- Python 3.10+
- [google-genai](https://pypi.org/project/google-genai/)
- API-ключ Gemini с подключённым биллингом
- FFmpeg — только для ускорения реплик в режиме `--fit`

Запросы к Gemini API платные. Лимит расходов на проект можно задать в AI Studio: вкладка Spend → Monthly spend cap.
